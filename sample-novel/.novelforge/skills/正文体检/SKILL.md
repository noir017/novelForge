# 正文体检

作者写完一章，问「这章哪儿不对」。这个技能是那套查法。

**它治什么病**：AI 腔、对话假、节奏塌、钩子没立住。不治剧情设计——那是细纲的事，那一层的问题去改 `.novelforge/plots/` 下那一段。

## 铁律：一条结论一个出处

**每一条毛病都要带「文件第几行 + 原文」**，作者要能自己去看。做不到就别写那一条。凭印象说「对话有点假」是这个活最容易犯的错，而且错得看不出来。

## 工作流

### 1. 先读那一章

`read` 目标章。范围就是这一章，不要顺手读前后三章——体检的是这一章的文字，不是它的剧情位置。

作者没说是哪一章时问一句，不要猜。

### 2. 按四类逐条扫

顺序是固定的，从最硬的往最软的走：

**第一类：AI 腔**（判据最硬，先扫）
拿 `references/AI味词表.md` 里的一级禁用词与禁用句式逐条对。**用 `search` 搜，不要靠读**——一级禁用词是可以精确命中的，读一遍会漏。搜到一处记一处，带行号。

`references/去AI味详解.md` 里有十种模式的详细判据与改法，拿不准某一处算不算时查它。

**第二类：对话**
- 有没有人物直接说出自己的情绪（「我很生气」）？
- 有没有信息倾倒——一个人物给已经知道的人解释设定？
- 对话标签是不是全是「缓缓开口道」这类？
- 每一句台词，说话的人想从对方那里拿到什么？答不上来的那几句就是废话。

**第三类：节奏**
- 一整段里句子长度是不是一个样？
- 有没有连着三段都在同一个场景、同一种情绪里？
- 这一章有没有一处「什么都没发生的一两秒」——强情绪场面缺了那个空白，读起来会赶。

**第四类：钩子**
章首第一句抓不抓得住人？章尾停在哪：停在一个**事件**上，还是停在一句形容词式的预告上（「更大的风暴即将来临」）？

`references/质量清单.md` 是完整的检查表，上面四类是它的主干，要更细就查它。

### 3. 排序，只讲前五条

按「读者真的会被绊到吗」排。前五条每条讲清楚：**在哪、原文是什么、为什么不行、改成什么**。其余的列成一行一条。

**不要一次报三十条。** 作者改不完，也分不出轻重。

### 4. 药方落到工程文件上

| 发现 | 落到哪 |
|---|---|
| 这一类毛病以后都别再犯 | `.novelforge/style.md`，加一条具体的禁令（写清楚禁什么、替代写法是什么） |
| 这个人物的说话方式一直没立住 | 那个人的角色卡（`.novelforge/characters/`），补「说话习惯」 |
| 这一章的剧情本身就撑不住 | 那一段的细纲（`.novelforge/plots/` 下），说清哪一环缺了 |
| 具体某一句写坏了 | 指出 `文件:行号` 与该改成什么，**由作者决定改不改** |

**不要主动去改已发布的正文。** 报出位置和建议，落盘的判断权在作者。

## 反面清单

- **不要凭印象断言。** 没搜到就说「搜了这几个词没有命中」。
- **不要把作者的风格当毛病。** 他一直这么写、而且写得有效的东西，不是 AI 腔。判之前先读一遍 `.novelforge/style.md`。
- **不要改剧情。** 这一层只看文字。剧情不对是上一层的事，说一句就够，不要在这里重排。
- **不要在报告里复述整章内容。** 作者刚写完，他知道自己写了什么。
