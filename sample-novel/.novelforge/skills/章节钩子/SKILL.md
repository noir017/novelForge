# 章节钩子

一章的开头决定读者读不读下去，结尾决定他翻不翻下一章。**这两处不能顺着写完就算。**

## 章尾：先按本章情绪选类型

| 本章情绪 | 选哪种钩子 |
|---|---|
| 悬念、未知 | 突然揭示 / 神秘物品 / 留白 |
| 紧迫、危机 | 紧急危机 / 倒计时 / 未完成动作 |
| 反转、真相 | 身份反转 / 隐藏含义 / 回声 |
| 情感、关系 | 两难抉择 / 承诺威胁 / 情感转折 |
| 氛围、日常 | 意象钩子 / 离奇消失 / 信息差 |

## 章尾十三式

| 名称 | 做法 | 例 |
|---|---|---|
| 突然揭示 | 抛出一条改变全局的信息 | 「信上的日期，是他死后第七天。」 |
| 紧急危机 | 下一章必须回应的威胁 | 「裂缝在扩大，灵石还差三块。」 |
| 未完成动作 | 动作被新变量打断 | 「他刚伸手，手腕被人扣住。『别动。』」 |
| 身份反转 | 身份真相偏离预期 | 「档案上写着：林小月，已故。」 |
| 两难抉择 | 被迫在两个坏选项里选 | 「签了，公司保住，但他得进去。」 |
| 神秘物品 | 重要而含义未知的物件 | 「包裹里是一把钥匙，附了张纸条：『你欠我的。』」 |
| 倒计时 | 时间不够用 | 「医生说还有三个月。那是两个月前的事。」 |
| 承诺／威胁 | 有人宣布了行动意图 | 「今晚十二点之前，我会告诉所有人。」 |
| 离奇消失 | 不可能的消失 | 「手铐还在，人没了。门没开过。」 |
| 隐藏含义 | 表面正常，实则暗藏信息 | 「『你和妹妹真像。』可她是独生女。」 |
| 意象钩子 | 反复出现的意象变了 | 「枯了一个月的茉莉，冒出了花苞。」 |
| 回声钩子 | 章尾呼应章首，关键细节改了一处 | 首：「她说她永远不会原谅他。」尾：同一句，加「但她的手攥得更紧了。」 |
| 留白钩子 | 只写反应，不写发生了什么 | 「他看了信。脸色变了。把信叠好放进口袋。」 |

## 章首七式

悬念对话开局 · 闪前碎片 · 倒计时开局 · 神秘独白 · 反差场景 · 未完成动作开局 · 意象预示

> 未完成动作开局：「他刚把钥匙插进锁孔，门里传来一声轻响。」
> 反差场景：「一边是婚礼现场，香槟塔堆得老高。另一边，医院走廊的灯在闪。」

## 四条铁律

1. **钩子是事件，不是形容词。** 「一场巨大的危机正在逼近」不是钩子，「他数了数，还剩两颗子弹」才是。
2. **不要在钩子里给答案。** 截断的那一刻就停，解释留给下一章。
3. **一章只留一个钩子。** 结尾连抛三个悬念，读者一个都记不住。
4. **不要为了钩子扭曲剧情。** 这一段本来收在一个平静的局面上，就让它平静地收——硬塞一个爆炸，下一章还得圆回来。

## 强度按阶段调

开篇前三章必须强（截断、危机、系统激活这一类）；中期日常可以用信息差、对话悬念这种中等强度；高潮前回到强钩子。**全程满弦，读者会疲**。
