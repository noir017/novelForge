# 场景与章节重写流程

## 一句话原则

不要把原文「润滑」得更顺。先找这场戏真正要改变什么，再围绕改变重写。

## 单场景流程

1. 定场景功能。
   这场戏是建立关系、暴露秘密、制造误会、升级冲突、兑现爽点、埋伏笔，还是让人物付代价？
2. 定人物目标。
   主角此刻想要什么？对手想阻止什么？旁观者能改变什么？
3. 定压力来源。
   压力可以来自时间、身份、金钱、伤病、舆论、权力、亲情、证据、空间限制。
4. 定失败点。
   让人物至少有一次判断不准、话说错、证据不够、动作慢半拍。
5. 定转折。
   转折必须来自前文铺垫，不要凭空出现救兵、神物、系统奖励或他人降智。
6. 定余波。
   场景结束后，人物关系、资源、心理、外部局势至少有一项改变。

## 整章精修流程

1. 先写章节功能：这一章结束时，读者应知道什么、担心什么、期待什么。
2. 标出核心情节：通常 2 到 4 个，不要每段都制造高潮。
3. 给每个核心情节补「铺垫、过程、余波」。
4. 把说明性段落改成场景推进。
5. 检查每 300 到 500 字是否有压力变化或情绪落点。
6. 检查章末是否留下下一章必须读的具体钩子。

## 常用改写动作

- 把「他很愤怒」改成他做错一件小事、说短一句话、压住一个动作。
- 把「众人震惊」改成一个人没接住茶杯，一个人改口，一个人开始重新算账。
- 把「她决定反击」改成她先试探、失败、发现漏洞，再冒险出手。
- 把「背景介绍」拆进物件、称呼、规矩、债务、伤痕、旧账。
- 把「大段内心」拆成动作、对话、环境压迫和一句关键判断。

## 情绪曲线

一章不要从头紧到尾，也不要一路平铺。

可用曲线：

- 压迫 -> 误判 -> 小胜 -> 更大代价
- 平静 -> 异常 -> 试探 -> 暴露
- 爽点 -> 反噬 -> 关系裂缝 -> 新钩子
- 日常 -> 旧伤被碰到 -> 情绪失控 -> 选择改变

## 章末钩子

优先使用：

- 已烧毁的证据重新出现。
- 最不该来的人到了现场。
- 主角刚赢下的小胜利暴露出更大漏洞。
- 一句称呼变化说明关系已经变了。
- 看似无关的小物件和前文伏笔对上。

避免使用：

- 只说「更大的危机来了」但不说危机是什么。
- 用梦、昏迷、系统提示强行断章。
- 每章都靠反派冷笑或神秘人登场。
