# 规划时的前情分三段：大纲与拆细纲不再随章数涨

> 2026-10-22。单独一件，**在 main 上直接开发**。接着 [2026-10-21-outline-per-chapter.md](2026-10-21-outline-per-chapter.md)（按远近带）与 [2026-10-22-outline-from-plots.md](2026-10-22-outline-from-plots.md)（大纲是各章梗概的汇总）。起因：盘点上下文时实测（128k 窗口、第 3 级）——写正文与章数无关（约 2 万 token），续写大纲、拆细纲却随章数线性涨：「更早的只带第一行」每章约 140 token、强制带、不受详细度管，第 300 章时续写大纲 4.8 万、拆细纲 6.3 万，七八百章撑爆窗口；拆细纲时大纲与前序细纲一览把同一批细纲各带一遍。

## 作者定的（2026-10-22）

| # | 问题 | 定案 |
|---|---|---|
| 1 | 全文大纲落后（只有批量写章、补齐、手动重建才更新）时远段怎么办 | **照样封顶**，明细里写「全文大纲只写到第 k 章：第 k+1–c 章这次没带」；不自动调模型 |
| 2 | 中段上限 | **沿用 `plotListMax`**（30 / 50 / 100 / 不限），不另设一项、不改数 |
| 3 | 拆细纲去重之后区间前 10 章的梗概 | **不带**：已经拆过的章由前序细纲一览（关键事件）与前几章细纲带 |
| 4 | 真实模型试跑 | **跑**：假的 300 章长工程，续写大纲、拆细纲各一次 |

## 三段（大纲阶段：续写 / 重写 / 讨论大纲）

| 段 | 哪几章 | 怎么带 |
|---|---|---|
| 近段 | 区间前 10 章到区间末（没给区间：最后 10 条） | 整条，P0 force（不变） |
| 中段 | 近段再往前，最多 `plotListMax` 章 | 一章一行（梗概第一行，≤100 字），**不强制**：放不下从最老的丢起 |
| 远段 | 更早的 | 不逐章列，交给全文大纲 |
| 区间之后已排好的 | 重写时 | 一章一行，**不强制**：放不下从最远的丢起（不封条数） |

- 填预算的先后：近段（强制）→ 中段（由近及远）→ 区间之后（由近及远）。还是一个条目 `outlineDoc`，截过的标 degraded。
- 全文大纲在大纲、细纲两张配方里 **P2 → P1**：它要接住远段。
- 明细（第 2 条）：哪几章整条、哪几章一行；远段「第 1–c 章没逐章列（只列最近 N 章，上下文详细度「X」），前情看全文大纲」；全文大纲没有或没写到 c 章时照实说；预算截掉的写明哪几章。

## 拆细纲：同一批细纲不带两遍

- `outlineDoc` 只带**这一次要拆的**：批次是区间里那几条（空壳上的梗概就是这一次的上游），外加**区间前面还没拆的空壳**（没有关键事件，前序细纲一览不列它们）；单章时这一章的梗概已经在本章细纲里，只剩前面的空壳，一条都没有就不出这一层。区间之后的照旧不带。
- 已经拆过的章：前几章细纲（单章，`plotPrev`）+ 前序细纲一览（`plotList`，最多 `plotListMax` 章）。一览也改成**放不下从最老的丢起**（从前整份丢），封顶时同样写明更早的看全文大纲、全文大纲写到哪。
- 更早的：全文大纲（P1）。

## 预计（估算，第 3 级、128k 窗口）

| 调用 | 第 100 章 | 第 300 章 |
|---|---|---|
| 续写大纲 20 章 | 2.1 万 → 约 2 万 | 4.8 万 → 约 2.2 万 |
| 拆细纲 5 章 | 3.7 万 → 约 2.1 万 | 6.3 万 → 约 2.1 万 |
| 写正文 | 不变 | 不变 |

第 4 级仍然不封条数，但中段与一览都按预算截，不会再因强制层超长被服务商拒。

## 不做

- 按卷折叠（没有卷简介可用）；更准的 token 计数；写正文那张配方；全文大纲自动更新。
- 「区间之后已排好的」不封条数：它只在重写中段时出现，量取决于排到了多远，不随写到第几章涨。
