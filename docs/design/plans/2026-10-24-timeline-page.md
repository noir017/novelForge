> 2026-10-24。作者用了 v0.2.7 的时间线（[2026-10-24-story-timeline-rework.md](2026-10-24-story-timeline-rework.md)「五」），提了三处：
> ① 点历法那一行就弹设置，反人类，设置放右键就行；② 没有一个看得下去的时间线页面，时间线和叙事线挤在「叙事线总览」里，难以观看，
> 参考 [andrea-novel-helper](https://github.com/AndreaFrederica/andrea-novel-helper)；③ 点时间线里的一章打开正文是何意味——找时间线
> 要回头看每一章正文吗。我给了方案，作者定：**竖排，单独一个总览页面，和叙事线总览分开；其余按推荐**。
> 本稿只管界面：时间线的格式、推算、对账、认时间一概不动。标 ⚑ 的是本稿自定的取舍。

## 借鉴了 andrea-novel-helper 什么

它的时间线是作者手写的 `.tjson5`（事件、连线、自由画布 + 一条只能看的横轴 + 按分组的甘特），日期只认公历，不从正文抽。我们的时间是
同步时从正文推出来的、一章一行，所以只借三样：**时间轴按日子排、对不上的直接标红**、**卡片上带它关联的东西**（它是角色与章节，我们是
这一章在各条线上发生了什么）、**回忆用虚线**。

## 一、编辑区「时间线总览」（新的特殊标签）

和「叙事线总览」并排的另一个不对应文件的标签（`editor/store.ts` 的 `SpecialTab`），只在独立版、桌面版有（插件形态没有内置编辑器，
同叙事线总览，能力探测）。数据按需要：显示出来时发 `requestTimelineOverview`，后端回 `timelineOverview`（纯读盘、不调模型、不落盘）；
显示着收到 `state` 停一下再要一次。

```
时间线总览  简单历 · 起点 大衍三年三月初七 · 推到第 30 章 · 故事第 46 天    [只看有问题的] [全部线 ▾]   [刷新]
⚠ 第 4 章：前面推下来是三月初八，正文写三月十五（差 7 天），已按正文对齐
──────────────────────────────────────────────────────────────
大衍三年三月 · 春
  初七   ●─ ┌ ● 第 1 章 楔子                         傍晚 → 深夜 ┐
  第1天  │  │ 依据「连日大雨的第三天傍晚」                          │
         │  │ [名册之谜] 林昭拿到名册  [未归属] 埋〈玉佩的来历〉     │
         │  └────────────────────────────────────────────────────┘
         │  ┌ ● 第 2 章 客栈里的女人                  同一天 夜里 ┐ …
         ┆  5 天后
  十三   ●─ ┌ ◆ 第 4 章 空匣             清晨 → 十五 夜里 · 3 天 ┐
         │  │ 正文写明三月十五「今夜便是十五」                       │
         │  │ ⚠ 前面推下来是三月初八，正文写三月十五，已按正文对齐   │
         │  └──────────────────────────────────────────────────┘
         │      ┌╌ ↺ 第 6 章 同路（回忆，约二十年前） ╌┐
大衍三年四月 · 夏
  初一   ●─ ┌ ★ 第 8 章 铁匠铺（你定的） …
```

- **轴**：一个故事日子一行（同一天的几章叠在一起，按章号），左边写那一天（有起点写 `初七`，下面小字 `第 1 天`；没起点只写 `第 8 天`）。
  ⚑1 **按故事日子排**，不按章号：往回跳的章排到它那一天去（对账照旧报它）——时间线要看的就是故事里谁先谁后。
- ⚑2 **只压空白、不按比例**：中间没有章的日子压成一行「N 天后」（差 2 天以上才有这一行；次日不画，日子变了一眼看得出）。
- **月份分隔**（填了起点）：月份变了插一行 `大衍三年三月 · 春`（季节按历法现算，同对账的口径），年份没变的只写月。没起点不分隔。
- **卡片**（一章一张）：状态点、`第 N 章 标题`、右边那一天的时段（`清晨 → 夜里`，跨天的 `→ 十五 夜里 · 3 天`）；下面依据 / 推测 / 正文写明 /
  你定的；然后是**这一章发生了什么**：
  - 叙事线的**实际**事件（计划的不画），一条一个：线名做成彩色小标签 + 事件；伏笔的写 `埋〈玉佩的来历〉`。⚑3 最多 3 条，其余「还有 N 条」，
    点开看全。⚑4 线的颜色按叙事线的排序前 8 条各一色、**不循环**（实施时改的：循环会让两条线撞色），第 9 条起与「未归属的伏笔」一样灰；
    名字总写在标签上，颜色只是帮着认。8 色是一套校验过色盲区分度的分类色，深色一套、浅色与护眼一套。
  - 这一章一条事件都没有：细纲的梗概（淡色）。
  - 对账报了这一章：红字一条一行，卡片左边一道红边。
- **回忆章**（⚑5）：挂在阅读顺序上前一章那一天里，跟在那一章后面，缩进、虚线框、↺；写「回忆（约二十年前）」。它的日子推不出来，不上轴。
- **还没推、推不出、认不出的章**：照推算的位置（按紧接上一章算）放上去，状态点照工程页（`·` `?` `✕`），卡片淡一些。时间线写到的最后一章
  之后、同步过还没推的章不上轴，最上面一条 ⚠ 说「第 31–35 章还没推」（⚑6）。

### 交互

- **单击一张卡片：展开 / 收起详情**（同时标成选中）。详情：开头 → 结尾的全称、故事第几天、比上一章、历时；依据原文 / 推测理由；正文写明的
  日子与原文、照它对齐了几天；季节与原文；对账的几条；这一章在各条线上的全部事件（带原文证据）；细纲的「时间地点」。
- **右键一张卡片**：改时间…、重推这一章、从这一章起重推、打开正文、打开细纲、打开时间线文件。改时间、重推都是工程页同一个动作
  （`projectAction`），后端照旧先问。
- **右键标题栏与空白处**：改历法与起点…、填为起点（有建议时）、补推时间（有还没推的）、重推机器写的 N 行、打开时间线文件、刷新。
  ⚑7 标题栏上只放「刷新」与两个筛选，设置与补推、重推都在右键（作者那条：设置放右键）。
- **筛选**（只在前端，不记住）：「只看有问题的」只留对账报了的章与推不出、认不出的章；「线」下拉只留在那条线上有实际事件的章。
  筛掉之后空出来的日子不画，「N 天后」照留下的那几天重算。
- **从工程页过来**：带章号就展开那一张、滚过去（见「二」）。

## 二、工程页「时间线」组

- **去掉第一行「历法与起点」**。历法与起点挪到组标题的悬停里；「改历法与起点…」只在右键（组标题、组里空白、每一行都有）。
  - 没填起点、正文写明过日子：对账那几条里多一条 `⚠ 没填起点：第 3 章写了「三月初七」，第 1 章是三月初五`，右键「填为起点」。
  - 起点认不出：一条 `⚠ 起点「很久以前」认不出，先只显示第几天`，右键改。
- **点一章：打开时间线总览，展开这一章**（不再打开正文，推翻上一稿 ⚑10）。打开正文挪到右键「打开这一章」。
  - ⚑8 插件形态没有内置编辑器：点一章打开时间线文件（时间线的原文，至少是看时间，不是看正文）。
- **点一条 ⚠**：带章号的打开总览、展开那一章；不带的（「第 31–35 章还没推」）打开总览。插件形态照旧打开时间线文件。
- 标题旁的「总览」打开时间线总览（原来打开叙事线总览、滚到时间线那一组）。「补推时间」「重推」照旧。

## 三、叙事线总览

- 去掉「时间线」一组（「故事时间」那一行）与表头的月份带：它只管线与伏笔。
- 列头与格子的悬停里照旧带一句「这一章是哪天」（`三月十四 清晨`），伏笔名的悬停照旧带「埋下 N 天」。
- 叙事线组标题旁的「总览」只看有没有线、有没有未归属的伏笔，不再看时间线。

## ⚑ 汇总（本稿自定的）

1. 轴按故事日子排，同一天按章号；往回跳的章排到它那一天。
2. 只压空白、不按比例：差 2 天以上插一行「N 天后」。
3. 卡片上的事件最多 3 条，其余点开看。

5. 回忆章挂在阅读顺序上前一章那一天里，缩进、虚线框，不上轴。
6. 同步过、时间线写到的最后一章之后还没推的章不上轴，最上面一条 ⚠。

8. 插件形态里工程页点一章打开时间线文件。
