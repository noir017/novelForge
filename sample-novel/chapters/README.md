# 章节

这里放**正文**，是这本书的唯一真相：定稿照它更新细纲，全书上下文从这里取正文，工程页的字数也报它。

一章一个文件，文件名的数字前缀就是章号（细纲号 = 章号）。细纲在 `.novelforge/summaries/` 下与正文相对路径相同的位置（`003-夜访.md` ↔ `summaries/003-夜访.md`，分子目录时细纲也在同名子目录里，扩展名一律 `.md`）。
写正文时模型产出的那一章直接落在这里；已经有内容时先让你对比再覆盖。可以分子目录收纳，章号仍然全书连续；在工具里改名、移动章节时细纲跟着搬。

老工程直接把已有的章放进来就行：没有细纲不影响，`chapters/` 里有文件就算写过那一章，可以直接定稿、直接进上下文。

创作流水线见 [../README.md](../README.md)。
