# 可数指标

不需要读懂内容就能算，一分钟跑完。用途是**把「我觉得读着怪」换成「这一章每千字 2.2 处微动作句，人类样本中位数 0」**——后者能变成提示词条款，前者不能。

## 先建基线，再定阈值

**别用绝对次数，用每千字频次**，否则章长一变阈值就废。也**别用别人拍的阈值**——不同书、不同题材差得远。拿这本书自己写得好的章（或作者认可的样章）跑一遍，那就是基线。

```bash
# 基线：对一批人工/满意章算每千字频次，看中位数与最大值
cd <章节目录>
for f in *.txt; do
  c=$(wc -m < "$f"); [ "$c" -lt 1500 ] && continue
  m=$(grep -o "了一下\|了一瞬\|了一眼" "$f" | wc -l)
  g=$(grep -o "目光\|视线" "$f" | wc -l)
  v=$(grep -o "说不清\|像是\|隐约\|复杂\|阴晴不定\|意味不明" "$f" | wc -l)
  d=$(grep -o "——" "$f" | wc -l)
  awk -v C=$c -v M=$m -v G=$g -v V=$v -v D=$d 'BEGIN{printf "%.2f %.2f %.2f %.2f\n", M*1000/C, G*1000/C, V*1000/C, D*1000/C}'
done
```

## 单章体检

```bash
f=<待审章文件>
c=$(wc -m < "$f")
echo "字数 $c"
for pat in "了一下\|了一瞬\|了一眼" "目光\|视线" "说不清\|像是\|隐约\|复杂\|阴晴不定\|意味不明" "——"; do
  n=$(grep -o "$pat" "$f" | wc -l)
  awk -v C=$c -v N=$n -v P="$pat" 'BEGIN{printf "%-45s %3d 次  每千字 %.2f\n", P, N, N*1000/C}'
done
```

`wc -m` 数字符（中文按字算），比 `wc -c` 的字节数直观。

## 一次实测

同一套指标，一边是 30 章人工连载（≈6.5 万字），一边是一章 4618 字的 AI 稿：

| 指标 | 人工中位数 | 人工最大 | AI 这一章 | 判别力 |
|---|---|---|---|---|
| 微动作句 `了一下/一瞬/一眼` | 0.00 | 0.71 | **2.17** | 强，超出人工最大值 3 倍 |
| `目光`/`视线` | 0.27 | 2.14 | 2.17 | 弱——人工也有 2.14 的章 |
| 含糊收尾词 | 0.41 | 3.56 | 2.60 | **无**，AI 这一章反而低于人工最大值 |
| 破折号 `——` | 0.00 | 0.77 | 3.03 | 强，超出 4 倍 |

两条要说清楚：

**微动作句和破折号是可靠指纹。** 人工中位数都是 0——人类作者基本不用这两样，AI 一章十几处。这两条直接定阈值，不用争论。

**含糊收尾词这个指标不成立。** AI 那一章的含糊问题是真实的（「目光复杂」「像是想说什么」「说不清来由的直觉」六七处扎堆在结尾三段），但**逐词计数抓不住它**——因为「像是」在人工文本里是极普通的比喻词（「像是水面上荡开的涟漪」），和「像是想说什么」这种回避式收尾混在一个计数里。人工样本里有一章跑到 3.56，比 AI 还高。

所以：**含糊只能靠读，不能靠数。** 判据不是词频，是「这个词有没有落到一个可被反驳的判断上」。写进指标表可以，但要标注它只是提示位置的探针，不构成结论。`目光/视线` 同理，判别力弱。

这也是这份文件最该记住的一句：**先用指标定位，再靠阅读定罪。数出来的只是嫌疑。**

## 数不出来但要人工点的

这些没法 grep，但比上面几条更致命——审章时必须逐项过：

| 项 | 怎么看 |
|---|---|
| 同一机制重复几次 | 战斗/解谜/说服的胜负手是不是同一招用了两遍以上，且条件没变 |
| 同一点子解释几遍 | 数一个设定被换着说法讲了几次（那份 AI 稿里「折线」讲了四遍） |
| 群众反应段落数 | 数「看台/众人/四周」起头的段落，看有几段的功能只是「说明主角很厉害」 |
| 钩子收支 | 开了几个悬念、收了几个 |
| 视角越界 | 有没有写主角看不见的东西、用主角不可能有的比喻 |
| 数字对账 | 轮次编号、年龄与境界、百分比（「耗去大半」和「剩余八成」并存） |
| 术语一致 | 真气/灵力、宗主/掌门这类同物异名 |

## 别做的事

- 别把指标当结论。含糊词那一列就是反例：AI 这一章数值低于人工，问题却真实存在。
- 别在没读懂剧情前先跑指标。剧情平淡是词频完全测不到的，而它比 AI 味更致命。
- 别把阈值写进代码。这是审稿时手跑的东西，不同书的基线不一样；固化成 lint 只会得到一堆假阳性。
