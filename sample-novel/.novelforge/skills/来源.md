# 这几份技能的来源

`去AI味` / `章节钩子` / `大纲结构` / `人物与对话` / `情绪弧线` / `正文体检` 六份技能的方法论内容，
提炼自 [oh-story-claudecode](https://github.com/worldwonderer/oh-story-claudecode)（MIT License，
Copyright (c) 2025-2026 oh-story-claudecode）的 `skills/story-long-write/references/`。

`正文体检/references/` 下三份是原样拷贝：

| 这里的文件 | 原文件 |
|---|---|
| `质量清单.md` | `references/quality-checklist.md` |
| `AI味词表.md` | `references/banned-words.md` |
| `去AI味详解.md` | `references/anti-ai-writing.md` |

其余五份的 `SKILL.md` 是**重写**的，不是拷贝：原仓库那批 reference 单份 8–30 KB，
而给创作模型的技能是**整份注入生成上下文**的，那个体量会把细纲、前文和文风一起挤出预算。
所以只留下落笔时真正用得上的判据与改法，并去掉了原文里那些依赖 bash 脚本、子代理与
另一套目录约定（`设定/大纲/正文/追踪/拆文库`）的部分——那些在 Novel Forge 里执行不了。
