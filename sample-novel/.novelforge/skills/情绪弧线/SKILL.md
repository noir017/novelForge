# 情绪弧线

读者记不住剧情，记得住情绪。**排一段剧情时先定它要交付哪一种情绪体验，再倒推事件。**

## 六种弧线，按这一段要干什么挑

| 弧线 | 形状 | 用在哪 |
|---|---|---|
| **V 形** | 先虐后治愈 | 单段最常用；低谷要真的低，回升才有重量 |
| **倒 V 形** | 先爽后反转跌落 | 卷中段转折；用来打断顺风顺水 |
| **W 形** | 多次起伏 | 较长的一段或一整卷；两次低谷不能同因 |
| **递进** | 逐级升级，不回落 | 升级流主线；每一级的门槛要肉眼可见地变高 |
| **延迟满足** | 长铺垫，一次爆发 | 大伏笔回收；铺垫期必须有别的东西撑着 |
| **急转** | 七八成处忽然拐弯 | 短段收尾；前面越顺，拐弯越有效 |

## 反转：七种，选一种，不要叠

身份反转 · 视角反转 · 动机反转 · 时间线反转 · 信息反转 · 认知反转 · **不反转**

最后一种是认真的选项：**该直给的时候就直给**。一段本来干净利落的复仇，硬塞一个「其实他早就知道」，只会让读者觉得作者在耍花招。

### 反转的三条时机铁律

1. **线索必须在前面出现过**，而且出现时是另一个意思。读者回头能找到，才叫反转；找不到，那叫作者说了算。
2. **反转点放在这一段的七到八成处**，留出后反应的余地。放在最后一句，读者只来得及愣一下。
3. **一段一个反转。** 嵌套两层已经是上限，三层读者会放弃跟。

## 中段加压四手段

一段写到中间容易泄气。四种加压方式，挑一种：

1. **加时限**——本来慢慢来的事，现在只有一天。
2. **抬代价**——原来输了只是丢面子，现在是丢命。
3. **撤支援**——本来能求的那个人，现在求不了了。
4. **加旁观者**——这件事现在有人在看，退不了了。

## 期待感：给了才能收

- **先承诺，再兑现。** 读者期待的东西必须是你前面明确许过的（一句话、一个物件、一个未解决的问题都算）。
- **兑现要超出一点，不要超出太多。** 完全按预期兑现是无聊，完全出乎预料是背叛。
- **不要连续三段都不兑现任何东西。** 每一段至少收掉一个小承诺，哪怕很小。

## 以小博大

情绪强度不来自事件规模，来自**赌注和角色的距离**。毁灭一座城不如毁掉他攒了三年才买下的那间铺子。排剧情时，把冲突落到**这个具体的人真正在乎的那样东西**上。

## 最后：这一段收在哪

每一段的结尾要写清楚**收在什么局面上**：谁在哪、关系变成了什么样、谁知道了什么、什么还没解决。下一段从这里接。

**不要写画面、天气、动作细节或台词**，那是写正文时才定的；也不要规定这一段从哪句话开头、到哪句话结尾。
