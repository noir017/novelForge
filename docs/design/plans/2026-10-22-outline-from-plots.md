## 存在哪

- 磁盘上**没有** `outline.md`。`.novelforge/outline.md` 这个路径仍是情节大纲的身份（编辑器标签、MCP 的读写、`@` 引用），读写都由网关接住：
  - **读**：各章细纲（按章号配对的那一份，`pairPlots`）里「梗概」非空的，一章一条拼成 `## 第N章：标题\n梗概`。`readOutline()` 只给条目；给编辑器的整份另带一行 `# 情节大纲` 与一段说明。
  - **写**：按章号拆回去（`model/outlineFile.ts` 的 `planOutlineSplit`，`Workspace.writeOutline` 落盘）。
- 只有梗概、别的几节都空的细纲叫**空壳**——大纲排到了、细纲还没拆。`isPlotFilled` 只看「关键事件」，空壳天然是「待写细纲」，状态机不用改。
- 老工程磁盘上若还有一份 `outline.md`，读写都绕开它（网关按种类走汇总），文件留在原处。

## 保存时怎么拆（`planOutlineSplit`）

| 情形 | 做什么 |
|---|---|
| 一条在，这一章有细纲，梗概或标题变了 | 只换「梗概」一节（外科式，别的节与 frontmatter 不动，先存一版历史）；标题变了走 `writePlot`（还没有正文时文件名跟着改，与改名同一条路） |
| 一条在，这一章还没有细纲 | 建一份空壳（有正文落正文的镜像，没有就跟上一章放在一起），`upstreamHash` 不记 |
| 原来有、这一回删掉了：空壳（除梗概外全空、没有正文、没定稿过） | 进回收站（`deletePlot`） |
| 原来有、这一回删掉了：已经排了细纲或写了正文 | ⚑ **不删**，说一声（要删去工程页删细纲）；汇总文档下一次读回来那一条还在 |
| 同一章写了两条 | 取先出现的（与原来一样） |
| 章号改了 | ⚑ **按章号对，不搬细纲**：在大纲里把第 5 章改叫第 6 章，等于改第 6 章那一条、删第 5 章那一条。插章仍要改文件名（与原来一样，没有批量顺延） |

覆盖审阅、乐观锁都在整份汇总文档上做（现有 ↔ 新版，审阅框里看到的就是会写下去的样子）；拆回去之后每份细纲各自存历史版本。

## 指纹链（第 18 条）

- 细纲的 `upstreamHash` 从「大纲里这一章那一条的指纹」改成「**这一章梗概的指纹**」（`plotSynopsisHash`）：排细纲、编辑器里存细纲时记下当时的梗概。
- 在汇总文档里改了一章的梗概，细纲 frontmatter 不动 → 这一章已经排了细纲（「关键事件」非空）的挂 ⟳（「大纲改了，细纲没跟」）。⚑ 空壳不挂。
- 定稿照正文改写梗概，`upstreamHash` 跟着刷成新梗概的指纹（原来没记过的照旧不记，第 18a 条）。
- 梗概在七节里，改梗概就是改细纲：写过正文的章，正文照样挂 ⟳（「细纲在正文之后改过」）。

## 生成

- **续写 / 重写大纲**：模型照旧输出 `## 第N章：标题` 一章一条；采纳时并进汇总文档（`mergeOutline`），审阅，拆回各章细纲。
- ⚑ **重写大纲只重写还没写正文的章**：写过的章，梗概由定稿照正文写，大纲那一条就是实际写成的样子，不再让模型照正文另整理一份。
- ⚑ **「从已写正文补齐」去掉补大纲那一步**：补齐先给没定稿的章整理细纲（带梗概），大纲自然就有了。
- ⚑ **拆细纲（批量）沿用已有的梗概**，不让模型改写——空壳的梗概是上游；单章重排细纲以模型产出为准（照旧走覆盖审阅）。蓝图合同里 `synopsis` 改成「大纲里这一章那一条，已有的照抄」，≤150 字。
- 定稿的「梗概」改成一句话加最多两句（≤150 字）。

## 连带

- 全书查找替换不再单列情节大纲（梗概在细纲里，搜细纲就搜到了）；`outlineOnly` 删掉。
- 新工程不建 `outline.md`。
- VS Code 壳：情节大纲开在一个虚拟文件系统（`novelforge:` scheme）上，读写同样经网关。
- 示例工程：删掉 `outline.md`，第 5–10 章改成空壳，第 1–4 章的梗概收成大纲那一条（指纹重算）。
- 外部的 autopilot 脚本（`skills/novelforge-autopilot`）算覆盖到第几章改成扫细纲的梗概。
- 历史版本、存档点不管 `outline.md`（它没有字节）：存回去时改了的每份细纲各自存历史，细纲在存档点里就退得回。
- 新的一份一条章标题都认不出（旧格式、散文式）却要整份换掉有条目的大纲：拒，不写（照拆会把空壳全删掉）。

## 我按推荐定的（⚑，待作者看）

1. ⚑ 用「梗概」，不新增一节；梗概收成一句话加最多两句（合同 ≤150 字，解码翻倍才截）。
2. ⚑ 汇总文档的路径沿用 `.novelforge/outline.md`；老工程磁盘上那份不读、不显示、不迁移。
3. ⚑ 大纲里删掉一条：只删空壳；排过细纲、写过正文、定稿过、记过设定的都不删，说一声。
4. ⚑ 改章号不搬细纲，按章号对。
5. ⚑ 批量拆细纲沿用空壳上的梗概与标题；单章重排以模型产出为准（走覆盖审阅）。
6. ⚑ 改标题不算改上游（只改名，不挂 ⟳）；空壳不挂 ⟳。
7. ⚑ 定稿刷新上游指纹；改过大纲那一条却照旧稿写了正文的章，定稿会把梗概改回正文的样子（⟳ 已经提醒过）。
8. ⚑ 重写大纲只重写没写正文的章；「从已写正文补齐」去掉补大纲那一步。
