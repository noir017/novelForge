# 正文层风格条款

可直接粘的提示词。落点两处：

- **首选 `.novelforge/style.md`**——工程私有，作者可改可删，不同书可以有不同尺度。正文阶段它是 P0 force，一定进上下文。
- **只有普遍成立的硬条款才动 `src/core/context/prompts.ts`** 的 `manuscript` 分支（那六条硬性要求）。那里是全项目共用，加一条就是给所有书加一条。

**按需挑，不要整份粘。** 每一条都在花作者的 token 预算。挑法：这一章真犯的错 + 它的替代方案。

---

## 叙述立场

```
全程紧贴 <主角> 的感知：只写她此刻能看到、听到、想到的。
不写她看不见的东西——他人背后的动作、远处人群的表情、别人心里想什么。
不使用她不可能有的比喻：她没坐过马车，就不许用马车作比。
```

## 必须承诺，不许含糊

这一条是治「不知所云」的主力，优先粘。注意它**不是**禁用词表——实测表明含糊词逐词计数抓不住这个毛病（「像是」在正常比喻里同样高频，见 [metrics.md](metrics.md)）。真正的约束是后半句：必须落到一个判断。

```
禁止以「说不清」「像是」「隐约」「复杂」「意味不明」「阴晴不定」收束一个观察。
凡写到某人的表情或态度，必须落到一个具体的、可被反驳的判断——
她认为对方在算计什么、在怕什么、在装什么。她可以判断错，但必须判断。
```

## 强度不许用数值

```
不得用数字表示强度：六成灵力、八成、丹田外三寸、一息的十分之一、约一肩宽。
强度只能用身体感受写：手麻到握不住、吸气时肋下发凉、汗流进眼睛里。
```

## 群众与外部认可

```
群众反应不得超过 1 处，且不得用于说明「主角很厉害」。
禁止路人复述刚刚发生的事——读者刚看过。
```

## 重复

```
一个设定只解释一次。已经写清楚的机制，后文只准使用，不准复述。
同一个四字词组全文只出现一次。
同一个胜负机制不得重复使用：第二次用必须改变条件（代价变高、对手已有防备、这次失手）。
```

最后一句是这一条里最要紧的——它不是禁令，是**升级要求**，直接解决「三千字等于一段」。

## 句式与节奏

```
「……了一下 / 了一瞬 / 了一眼」这类微动作句，全章合计不超过 3 次。
「目光」「视线」合计不超过 2 次。眼神不能承担情节。
单句成段不超过 2 处；破折号不超过 2 处。
```

微动作句与破折号这两条有实测支撑：人工连载里两者的每千字中位数都是 **0**，AI 稿分别是 2.17 和 3.03（见 [metrics.md](metrics.md)）。**阈值按书调**，先跑基线再定。要点是给一个具体数字——「少用」模型执行不了，「不超过 3 次」能。

## 感官

```
除视觉外，至少写进 3 处非视觉感受：气味、地面的硬度、汗、口腔里的味道、声音的远近。
天气一旦出现，必须在后文继续起作用，不许只当开场布景。
```

## 对白

```
每个角色的字面意思和真实意图必须至少有一处不一致。
禁止角色说出正好是读者需要知道的信息。
至少一个角色有可辨认的说话习惯：句子长度、爱用的词、不肯说完的句子。
```

## 开局

```
开篇 500 字内不得交代主角的任何优势——天赋、身份、修为、特殊能力一概不许。
这几百字只写她此刻缺什么、怕什么、忍着什么。
她的优势必须在被使用时才被读者看见，不许预先声明。
```

单独一条，效果立竿见影。

## 能力必须有代价

```
主角的特殊能力每次使用都要付出可感的代价，且代价在本章内兑现。
写出这个能力的一处盲区或失效条件，并让它在本章造成一次实际损失。
```

## 专有名词

```
每个新出现的专有名词必须携带一条只属于它的信息——
一个由来、一处代价、一句别人对它的评价。
做不到就不要起名，用「那个宗门」「那套剑法」代过。
```

这条治「灵云宗可以替换成任何名字」。它同时压缩篇幅：起不了名就写不了那一段，模型只好去写有内容的部分。
