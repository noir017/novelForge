# 审章：AI 味与剧情平淡

## 这个技能解决什么

AI 写的小说读起来不对，绝大多数时候不是错别字或设定 bug，而是两件事：

1. **语言风格**——文本是「摄像机 + 解说员」体：外部动作 → 微表情 → 群众反应，三拍一循环。叙述者只报告可见物，不承担观点；重要的话和不重要的话用同样的强调权重平铺，所以读者读完不知道哪句要记住。这就是「不知所云」的语言成因。
2. **剧情平淡**——这一拍的内容本身没有转折。主角没有想要的东西，没有付代价的选择，结尾状态和开头只差一个程度值（更强了 / 赢了）。

**这两件事修在不同的地方，别混。** 风格能在写正文的提示词里治好；剧情平淡治不了——它在正文生成之前就被上游定死了。给「主角越境赢了榜首」这一拍配再好的文笔提示词，也只能把一个无聊的拍子写得漂亮。

对应到本项目的四层流水线（见 [AGENTS.md](../../../AGENTS.md)）：

| 病灶 | 改哪里 |
|---|---|
| 语言风格 | 工程的 `.novelforge/style.md`（作者可改，首选）；普遍性的硬条款才动 `src/core/context/prompts.ts` 的 `manuscript` 分支 |
| 剧情平淡 | `prompts.ts` 里 `STAGE_DUTY.plot` / `JOB_TASK.plot` / `buildOutputContract('plot')`，以及卷纲那一层的 `plotSegment` |

**先判断是哪一层的病，再动手。** 判据：把这一章的剧情脉络用三句话写出来（谁要什么 / 谁挡着 / 结果如何）。三句话写得出且有转折 → 是风格病，只改正文层。写不出、或者写出来是「他赢了」这种单向结果 → 是剧情病，改正文提示词纯属浪费。

## 工作流

### 1. 先跑可数的（一分钟，不要靠感觉）

命令与实测基线见 [references/metrics.md](references/metrics.md)。**用每千字频次，不用绝对次数**，并且先拿这本书写得好的章建基线。

实测（30 章人工连载 vs 一章 AI 稿）只有两个指标真能判别：

- **微动作句**（`了一下 / 了一瞬 / 了一眼`）——人工中位数 0.00，AI 2.17
- **破折号** `——`——人工中位数 0.00，AI 3.03

这两条超基线就是问题，不用争论。而 `目光/视线` 判别力弱，**含糊收尾词逐词计数根本不成立**——AI 那一章的数值反而低于人工最大值，因为「像是」既用于回避式收尾也用于普通比喻。含糊只能靠读，不能靠数。

这一步的价值是**把「我觉得怪」换成「这一章每千字 2.17 处微动作句，人工中位数是 0」**——后者能变成提示词条款，前者不能。但记住：**数出来的只是嫌疑，定罪要靠阅读。**

### 2. 再判剧情（问五个问题）

对着这一章问，答不出就是那一项缺失：

1. 主角在这一章**想要**什么？（不是"想赢"这种通用愿望，是这一章特有的）
2. 她为此**放弃**了什么？两个选项都难受的那种选择在哪里？
3. 结尾的局面和开头相比，**性质**上哪里不同了？（「赢了 / 变强了 / 学会了」是程度变化，不算）
4. 这一章开了几个悬念、收了几个？
5. 如果整章删掉，后文哪一件事会失去前提？

第 5 问答不出来，这一章就是可删的。第 2 问答不出来，就是平淡的根因——**没有选择就没有戏**。

一个常见形态值得单独认出来：文本已经摸到了真正的戏（比如「她的异能不能让人知道」），但用「被打断」「来不及」「有人涌上来」把那个抉择躲过去了。这不是节奏问题，是回避。见到就点出来。

### 3. 开药方

产出必须是**能粘的条款**，不是感想。两份现成的清单直接取用：

- [references/style-rules.md](references/style-rules.md) — 正文层的风格条款，按需挑，粘到 `style.md` 的「禁用清单」等小节
- [references/scene-contract.md](references/scene-contract.md) — 剧情层的场景合同，粘到 plot 层的输出契约

挑条款时按这一章实际犯的错挑，**不要把整份清单倒给用户**。十条针对性的条款胜过三十条通用条款——后者会占掉正文生成的 token 预算（`style.md` 在正文阶段是 P0 force，见 [core/context/README.md](../../core/context/README.md)），还会让模型顾此失顾彼。

### 4. 演示一段

挑原文最病的一处（通常是重复三遍的那个机制，或者含糊收尾最密的那一段），按新条款重写 150～300 字，和原文并排。

这一步不能省。用户看条款判断不出效果，看改写能。而且改写会暴露条款自身的毛病——写不出来，说明条款只是禁令、没给替代方案。

## 高频病灶清单

按出现频率排，每条都附「为什么它是 AI 特有的」——这一点要讲给用户，否则条款看起来像随口定的规矩。

**重复即强调。** 同一个点子解释四遍、同一个胜利机制原样重复三遍、同一句意思换四种说法说（「但她看得见」/「她看得清清楚楚」/「可她依然看得见」）。模型在给自己的点子打气，而不是发展它。**这是「字多事少」最大的单一来源**——删掉重复的两遍，字数掉三分之一，剧情一点不少。

**含糊即深度。** 「说不清的表情」「目光复杂」「隐约觉得不对劲」「像是想说什么」。模型在**模拟内心而不承诺内容**：看着有味道，读完什么都没得到。治法不是禁用这些词（实测逐词计数抓不住它——「像是」在正常比喻里同样高频），是要求**落到一个可被反驳的判断**——她认为对方在算计什么、在怕什么、在装什么。她可以判断错，但必须判断。

**群众当鼓掌机器。** 「响起一片压不住的骚动」「四周顿时炸了锅」「然后看台炸了」，加上路人替读者复述剧情（「沈师兄三次术法都没放出来」）。文本不信任自己的场面，所以雇了合唱队。更深一层：这说明**这一章的情绪引擎是外部认可，不是内在渴望**——爽文条件反射。

**数值代替感受。** 「六成灵力」「八成」「丹田外三寸」「一息的十分之一」「约一肩宽」。伪精确，游戏血条式写法，且「约一肩宽」这种测量语气在紧张场面里语域完全不对。强度只能用身体写：手麻到握不住、吸气时肋下发凉。

**微动作句指纹。** 「攥了一下」「顿了一下」「愣了一瞬」「望了一眼」——这是最容易机械识别的一条。伴生的是**眼神承担情节**：`目光`/`视线` 高频出现，因为模型用眼神走位代替戏剧冲突。

**视角越界。** 限制视角写着，却插入主角看不到的东西（父亲背后攥手、远处看台的表情、别人心里想什么），或者用主角不可能有的比喻（她没坐过马车，却用马车车轴作比）。读者会下意识觉得叙述者不可信——「读起来奇怪」的一大来源。

**能力是开关，不是能力。** 主角的异能没有代价、没有射程、没有盲区、没有使用史。于是"关键时刻发现关键线索"不是人物能力的结果，是剧情临时授权的。**给能力加一条代价，比给它加三种用法有用得多。**

**开局把 buff 叠满。** 前 300 字交代完身份 + 天赋 + 修为 + 异能 + 名号，反面信息（不利传言）主角毫无反应。人物没有缺口，读者没有入口。附带风险：叠出来的数字常互相打脸（14 岁筑基、17 岁还是筑基中境 —— 三年一个小境界，这个"天才"其实很慢）。

**所有人一个腔调。** 除了负责打感叹号的那一个，其余角色说的都是货架上的句子，换任何一本书的任何一个师兄都成立。且**对白全是明牌**：每句台词的字面意思和真实意图完全一致，且正好是读者需要知道的信息。

**专有名词不携带信息。** 灵云宗、流云剑法、刑罚堂、青衫人影——全部可以替换成任何名字而不影响一个字。

**钩子只开不收。** 旧疤、远处的陌生人、长老意味深长的一眼、师尊「像是想说什么」——同一章堆五个，一个不响，而且味道全一样（都是"神秘暗示"这一种口味）。读起来不像伏笔，像是在撒"伏笔味"的调料。量化规则见场景合同第 3 条。

## 校对级问题：报，但别摆在前面

轮次编号自相矛盾、术语混用（真气 / 灵力）、百分比冲突（「耗去大半」与「剩余八成」并存）、病句、境界年龄算不上账、称号官职混乱（宗主 vs 掌门）。

这些要报——它们是真错，而且好修。但**别摆在诊断的开头**：读者不会因为「第四场」和「第八轮」打架而弃文，会因为读完三千字没被任何东西勾住而弃文。先说病灶，校对问题收在最后一段。

## 反面清单

- 不要在没读懂剧情前先数词频。指标是证据，不是诊断。
- 不要把风格条款开给剧情病。判据在上面「工作流」第一节。
- 不要一次给三十条条款。挑这一章真犯的。
- 不要只给禁令。每条禁令都要有「那该怎么写」——否则模型只会换一种方式犯同样的错。
- 不要建议「让文笔更优美」「增强代入感」这类不可执行的话。这正是 [stylePrompt.ts](../../core/features/stylePrompt.ts) 明令排除的东西。
